# 2.2.0 - Adaptive Compose calendar release

Adaptive layout, multi-window and foldable support for Compose calendar views.

### Added

- Layout and state contract for adaptive multi-month views (`docs/ADAPTIVE_LAYOUT.md`), establishing minimum month widths (336 dp without week numbers, 376 dp with 40 dp week numbers at 48 dp targets) and narrow-container fallback.
- Comprehensive constraint and monotonicity tests for multi-column grids in `CalendarMonthColumnsTest`.
- Adaptive two-pane layout (`CalendarSampleAdaptiveLayout`) for tablets and expanded screens (>= 840 dp), displaying controls and calendar views side by side.
- Fold and hinge awareness (`androidx.window:window:1.5.1`, sample-only) supporting book and tabletop postures without cross-hinge occlusion.
- Adaptive dialog viewport height calculation preventing vertical clipping in landscape or compact heights.
- Adaptive two-pane layout in `HeatMapViewActivity` for large screens and foldables.
- Modularized sample architecture with clean separation of UI state (`CalendarSampleState`), controls (`CalendarSampleControls`) and screens (`CalendarSampleScreen`).
- Unit tests (`CalendarSampleStateTest`) and instrumentation tests confirming full state survival across activity recreation and configuration changes.

### Compatibility

- 100% binary-compatible with `2.1.0`. All public and protected JVM APIs in `:library`, `:calendar-gregorian`, `:calendar-hijri` and `:calendar-solarHijri` remain unchanged.
- `:library` and calendar engines remain completely dependency-free of window/fold packages.
