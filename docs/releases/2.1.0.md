# 2.1.0 - Compose calendar release

Native Jetpack Compose calendar library release with a binary-compatible 2.0.1 bridge.

### Added

- Calendar-month, week, agenda, marker, range-policy, adaptive-month and style APIs.
- A version-aligned `calendar-bom` publication.
- Pluggable Hijri date providers and saveable provider-aware Hijri month state.
- A dependency-free public JVM API guard and independent consumer coverage.

### Compatibility

- All 248 public/protected JVM members from the published 2.0.1 AARs retain identical descriptors.
- Hidden delegation overloads preserve the previous selection, month-grid and engine-month signatures.
- New source resolves the current APIs; no deliberate breaking change.

### Verification

- Two complete API 29 instrumentation runs passed on the identical release tree:
  `2eb0fdbc5c1ec9d5cfbeae1570eddd7e9bf37a41` (run 43081287870) and
  `bd046a188d9a661e657affe580c7a7fa1a3e98ba` (run 43082385555).
- JVM tests, lint, publishing verification and the public API guard passed for the release commit.
- The JitPack 2.1.0 build reports `BUILD SUCCESSFUL` and lists AAR, POM, module metadata and
  sources for all four modules, plus the BOM POM/module metadata.
- A standalone consumer with the local candidate repository removed resolved the BOM and all
  four modules from JitPack without `mavenLocal()`; the 2.0.1-compatible source and the
  provider/range-policy source compiled.
