# 2.3.0 - Native Solar Hijri module

Introduces `:calendar-solarHijri-native`, a dependency-free Solar Hijri (Jalali) calendar module alongside the existing `:calendar-solarHijri` module.

### Added

- **`:calendar-solarHijri-native`** (`com.develotter.calendarview.calendars.solarHijriNative`):
  - `SolarHijriEngine`: pure-Kotlin port of the Borkowski (1996) break-table algorithm (`-61..3177` AP, MIT-licensed `jalaali-js` logic, attributed in `NOTICE`), using `jalCal` as the single source of truth for leap years and conversions.
  - `SolarHijriDate`: `@Immutable` `Comparable` value type with `plusDays`/`minusDays`/`plusMonths`/`minusMonths` (day clamping), `withYear`/`withMonth`/`withDayOfMonth`, `toEpochDay()` matching `LocalDate.toEpochDay()`, and `now(clock: Clock)`.
  - `SolarHijriLocale`: Persian (`fa`), Dari (`fa-AF` / `prs`), and English month names with locale-aware digits.
  - Compose UI & state parity: `SolarHijriNativeCalendarMonth`, `SolarHijriNativeMonthData`, `SolarHijriNativeWeekData`, `SolarHijriNativeMonthState` (`rememberSolarHijriNativeMonthState` with `Clock` support and engine-bound clamping), plus blank/disabled adjacent-cell guards at `-61-01` and `3177-12`.
- Added `:calendar-solarHijri-native` to `:calendar-bom`, `jitpack.yml`, `scripts/api-check.sh`, CI verification/publishing workflows, and the `calendarviewsample` demo app (`SampleCalendar.SolarHijriNative`).

### Compatibility

- 100% binary-compatible with `2.2.1`, `2.2.0`, `2.1.0`, and `2.0.1`.
- `:calendar-solarHijri` and `api/calendar-solarHijri.api` remain completely unchanged.
