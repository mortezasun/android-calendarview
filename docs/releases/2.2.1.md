# 2.2.1 - Adaptive Compose calendar hardening release

Adaptive layout hardening, minimum touch targets, fold geometry, state restoration suite and tablet CI for Compose calendar views.

### Added and Improved

- Minimum month width enforcement guaranteeing full 48 dp day cell touch targets (`CalendarSampleMonthWidth.kt`: 336 dp without week numbers, 376 dp with 40 dp week numbers), verified in `CalendarSampleMonthWidthTest`.
- Adaptive pane and secondary viewport height calculations (`CalendarSamplePaneHeights.kt`) clamped between safe minimum and maximum bounds, eliminating vertical clipping in landscape or compact heights, verified in `CalendarSamplePaneHeightTest` and `CalendarSampleSecondaryHeightTest`.
- Hinge and fold geometry handling (`CalendarSampleFoldGeometry.kt`) with window insets and layout direction support, verified in `CalendarSampleFoldGeometryTest`.
- Continuous layout and fold transition test (`CalendarSampleAdaptiveLayoutTest`) validating unbroken state retention across compact, wide, vertical fold, horizontal fold, no fold, week toggle, and calendar engine switches.
- Comprehensive `StateRestorationTester` suite (`CalendarSampleStateRestorationTest.kt`) asserting genuine `SavedInstanceState` preservation across process death/activity recreation for all 17 sample properties, range selection endpoints, and range interior.
- Automated Android Tablet CI workflow (`android-tablet.yml`) verifying the entire test suite on a 1600x2560 240 dpi API 29 tablet emulator in addition to phone emulators.
- Consolidated adaptive documentation (`docs/ADAPTIVE_LAYOUT.md`, `docs/ADAPTIVE_HEIGHTS.md`, `docs/ADAPTIVE_REVIEW_FIXES.md`, `docs/ADAPTIVE_TABLET_CI.md`).

### Compatibility

- 100% binary-compatible with `2.2.0`, `2.1.0` and `2.0.1`. All public and protected JVM APIs in `:library`, `:calendar-gregorian`, `:calendar-hijri` and `:calendar-solarHijri` remain unchanged.
- `:library` and calendar engines remain completely dependency-free of window/fold packages.
